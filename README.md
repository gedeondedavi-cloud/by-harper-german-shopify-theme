# By Harper German Shopify Theme

German version of the By Harper Shopify theme.

This repository contains the theme source code and is part of my front-end development portfolio.

## About the project

This is a complete Shopify theme version prepared for the German market.

The project includes the theme structure, Liquid sections, snippets, templates, JavaScript, CSS and locale files.

## Technologies
